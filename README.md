# Mohammad Riskhan — Portfolio

A responsive React portfolio built with Vite, Tailwind CSS, and Lucide React. It presents Mohammad's full-stack engineering profile, CV-matched project work and skills, education, and contact details.

## Development

```sh
npm install
npm run dev
```

## Validation

```sh
npm run lint
npm run build
```

## Structure

- `src/components/` — modular page sections and reusable project/skill components
- `src/App.css` — responsive layout, theme, and portfolio-specific styles
- `src/index.css` — global styles and Tailwind import
- `public/Riskhan_CV.pdf` — downloadable CV used by the navigation and hero buttons

The Skills section filters skill groups by domain. Project cards link to the GitHub profile, and the POS project includes its live deployment link.
